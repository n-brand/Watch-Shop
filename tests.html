Test 01

Lumen-Display in CSS

Das Display der Lumen ohne 3D und ohne Canvas: nur HTML und CSS. Es zeigt die echte Uhrzeit.

  • 7-Segment-Ziffern aus clip-path, unbeleuchtete Segmente schimmern schwach durch
  • Welche Segmente leuchten, steuert CSS über data-d; das Skript setzt nur die Ziffern
  • Doppelpunkt blinkt per CSS-Animation, skaliert über Container-Einheiten

Test 02

Räderwerk in 2D

Ein Schweizer Ankerwerk von oben, als SVG gezeichnet und in Echtzeit bewegt: Die Unruh schwingt mit 4 Hz und gibt das Räderwerk achtmal pro Sekunde einen Schritt frei.

  • Kraftfluss: Federhaus → Minutenrad → Kleinbodenrad → Sekundenrad → Ankerrad → Anker → Unruh
  • Jedes Rad greift in den kleinen Trieb des nächsten; Übersetzungen 96:12, 64:10, 75:8, 96:6
  • Sekundenrad 1 U/min, Ankerrad mit 15 Kolbenzähnen, Unruh 28'800 A/h mit ±270°
